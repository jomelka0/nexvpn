# Nex для Windows

Окно приложения (Edge в режиме app) + локальный сервер на Node.js + ядро Xray.
Подключение работает через системный прокси Windows (127.0.0.1:10809), переключатель — в настройках.

## Как это проверяется
- `node test/unit.js` — разбор подписок, сборка конфигов Xray, сохранение, системный прокси (команды).
- `node test/e2e.js` — настоящий браузер (Playwright/Chromium), тестовая панель подписок (`tools/ref/mock_server.js`)
  и подставной Xray (`test/fake-xray.js`, проверяет структуру конфига): импорт, пинг, подключение, статистика, переключение, отключение.
- В CI (GitHub Actions) каждый сгенерированный конфиг проверяется настоящим Xray: `xray run -test`.

## Что не проверяется без Windows и интернета
Реальный трафик через сервер провайдера, запуск окна Edge и запись системного прокси в реестр.
Если что-то не работает — Настройки → Диагностика → «Копировать отчёт».
