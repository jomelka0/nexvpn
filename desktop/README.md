# Nex для Windows

Окно приложения (Edge в режиме app) + локальный сервер на Node.js + ядра **Xray, sing-box, Mihomo**.
Подключение: системный прокси Windows (по умолчанию) или режим TUN (весь трафик системы; нужны права администратора).

## Ядра
| Ядро | Протоколы |
|---|---|
| Xray | VLESS (в т.ч. Reality), VMess, Trojan, Shadowsocks, готовые Xray JSON из подписок |
| sing-box | то же + Hysteria2, TUIC; **встроенный TUN** |
| Mihomo | то же + Hysteria2, TUIC |
«Авто» берёт Xray, а для Hysteria2/TUIC — sing-box или Mihomo. TUN для Xray и Mihomo идёт через tun2proxy (+ wintun.dll).

## Скорость пинга
Серверы проверяются параллельно (до 12 ядер одновременно), недоступные отсекаются быстрой TCP-проверкой за ~2 с,
остальные — реальным запросом через ядро.

## Как это проверяется
- `node test/unit.js`, `node test/unit2.js` — разбор подписок, конфиги всех ядер, выбор ядра, примитивы быстрого пинга.
- `node test/e2e.js` — настоящий браузер (Playwright), тестовая панель подписок и подставные ядра (`test/fake-core.js`):
  импорт, пинг 47 серверов, подключение через каждое ядро, статистика, TUN, переключение, отключение.
- В CI каждый конфиг проверяется настоящими ядрами: `xray run -test`, `sing-box check`, `mihomo -t`.

## Что не проверяется без Windows и интернета
Реальный трафик через сервер, запуск окна Edge, запись системного прокси и реальный TUN.
Если что-то не работает — Настройки → Диагностика → «Копировать отчёт».
